# HUMANLY AI Frontend

Advanced AI Text Detection & Humanization Platform - Frontend

## Features

- Modern, responsive React + TypeScript interface
- Light and dark themes
- AI Detector with dual analysis modes
- Text Humanizer with multiple modes
- Document Workspace for PDF/DOCX/TXT
- Writing Quality Analysis
- Comparison tools
- Export functionality

## Setup

1. Install dependencies:
```bash
npm install
```

2. Copy environment variables:
```bash
cp .env.example .env
```

3. Run development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Lucide React
- React Hot Toast
